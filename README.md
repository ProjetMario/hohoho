# HoHoHo Santa

Base de travail pour l’identité visuelle de **HoHoHo Santa**.

> **État du dépôt : import partiel.** Les fichiers disponibles dans la conversation sont ajoutés ici. Le code source de l’application actuellement hébergée sur Netlify n’a pas été récupéré et n’est pas inclus dans ce dépôt.

## Identité visuelle

Le dossier `branding/` rassemble les éléments graphiques disponibles et la palette destinée au site : rouge Père Noël, rouge profond, doré chaleureux, ivoire et blanc chaud.

La feuille `branding/palette.css` définit des variables CSS. Elle n’est pas encore intégrée au site en production.

## Application existante

- Site : https://hohohosanta.app
- Projet Netlify identifié : `hohohosanta-live`.
- Le dépôt n’est pas relié à un déploiement automatique par cet import.
- Les pages, routes, paiements et fonctions serveur de l’application ne sont pas présents ici.

**Ne pas déployer cette base à la place du site existant : elle ne constitue pas une application exécutable.**

## Sécurité

Ne jamais publier de fichiers `.env`, de clés API, de jetons d’accès ou de données utilisateurs. Le fichier `.gitignore` prévoit des exclusions de sécurité ; il ne retire pas des secrets déjà enregistrés dans un historique Git.
